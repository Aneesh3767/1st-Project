# 🌦️ Weather App

A clean and simple weather application that shows:

- Current temperature  
- Weather description  
- Humidity  
- Wind speed  
- Weather icon  
- **5-day forecast**

## 🚀 Technologies Used
- HTML  
- CSS  
- JavaScript  
- OpenWeather API  

## 📌 Features
- Search weather by city name  
- Live temperature & details  
- 5-day forecast cards  
- Weather icons  
- Responsive UI  

## 🔑 Setup
1. Go to https://openweathermap.org/api
2. Create a free account
3. Generate an API key
